# llm-websearch

[![PyPI](https://img.shields.io/pypi/v/llm-websearch.svg)](https://pypi.org/project/llm-websearch/)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](https://github.com/yourusername/llm-websearch/blob/main/LICENSE)

An LLM plugin that adds web search and deep search capabilities.

## Installation

```bash
llm install llm-websearch
```

## Usage

```bash
llm websearch "search query" 
```

```bash
llm websearch deep "search query"
```
